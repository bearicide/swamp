## CONTROLLED COLOR RETURN

Reintroduce color carefully as accent energy instead of full-spectrum UI overload.

### Accent Mapping
- cyan = navigation / system state
- magenta = music / media energy

- amber = rewards / alerts
- deep red = danger / arcade energy
